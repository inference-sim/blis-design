BLIS design

BLIS simulates an LLM serving cluster. It runs the router of llm-d, hosted in simulated time with no change to any routing decision, and Go ports of the vLLM and SGLang engines, each modelling an upstream commit. These pages explain how its code is divided into components, what each owns, and the rules that keep them correct.

What the design is

The design is a standing document. Every statement in it holds for every release: it says what must be true, and it has no dates or milestones. Release plans are separate and are not part of these pages. The design has a version number, and the rule for numbering versions is in the README of blis-design.

The code

The code lives under github.com/inference-sim. Start with inference-sim: the simulator, the substrate and one directory for each engine. The router fork, accuracy-dashboard and blis-config-search are separate repositories, and the component table of the design lists them all. To ask for a feature or report a problem, open an issue in the repository that owns the behaviour.

Each summary is a single HTML file that prints to US Letter. It links to the full design in the same folder.
