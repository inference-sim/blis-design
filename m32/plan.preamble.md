# BLIS M3.2 plan

This page joins three things: a summary of what M1 to M3.1 delivered, the M3.2 requirements, and a draft order of
the M3.2 workstreams. It is not yet the release plan. The requirements part is generated from `requirements.md`,
the source of truth.

## Delivered so far (M1 to M3.1)

M1 and M2 each ended with a milestone release. M3.0 (v0.18.0) and M3.1 (v0.18.1) are releases within M3. From
M3.1 on, only inference-sim is tagged, and the other repositories are pinned by commit (blis-design#22).

**Table M. Each milestone so far, and each release within M3, ended in an inference-sim release.**

| Milestone | Release | What it delivered |
|---|---|---|
| **M1** Foundations | inference-sim v0.16.0 (blis-substrate v0.12 and v0.13; accuracy-dashboard v0.4.0; blis-config-search v0.1.0) | blis-substrate created from the four M1-era repositories (blis-schemas, blis-catalog, blis-registry and blis-latency-kernel, now archived); data loading, document schemas, the ledger and the invariant registry; the dashboard's scorer moved onto the Result document; the deprecated `observe` and `calibrate` commands removed |
| **M2** Engine boundary | inference-sim v0.17.0 (blis-vllm v0.32.0-blis.N) | units as types; coverage of what InferenceX serves (catalog onboarding, registry pricing); like-for-like comparison on three axes; blis-vllm publishes `fields.json`. No point reaches G1 |
| **M3.0** | inference-sim v0.18.0 (blis-vllm v0.33.0-blis.1; blis-sglang v0.5.23-blis.1; router fork v1.0.0-blis.5; blis-substrate v0.15.0) | the port to vLLM v0.33.0; vLLM 0.32 and the engine kind `sglang` refused; the typed engine-settings carrier deleted; the dashboard's M3 baseline per engine, with grade ceilings; SGLang graded, not scored |
| **M3.1** | inference-sim v0.18.1, released 2026-11-18 (a patch on `release-v0.18`; the other repositories pinned by commit) | the first release to register and run the engine kind `sglang`; seven integration pull requests; review fixes, including the all-reduce lane keyed by backend (blis-substrate#373, for blis-substrate#116), p2p transfer at unequal TP, the P/D per-instance measured window, the router check, and the measured Muse DSpark acceptance |

The rows above name the repositories as they were; M3.2 builds the one-repository layout of design v3.0.0 (DC3).
